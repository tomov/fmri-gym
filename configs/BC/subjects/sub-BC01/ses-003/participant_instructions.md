# Session 3: instructions for the participant (ses-003)

One paragraph per cognitive task of `BC_sub-BC01_ses-003.sh`, in the order the script plays them. Buttons on the 932 gamepad: **1 = Y, 2 = A, 3 = X, 4 = B**.

## WCST (run 2)

"I want you to match a given card displayed on the bottom of the screen with one of four cards displayed on the top. Those four cards would not be changed, and only the card on the bottom would be changed for each trial. and you would press from 1 to 4 to select the card from left to right. You would see the feedback whether your answer was "right" or "wrong"."

*Source: `DBP_CogTasks_fMRI/WCS/README.md`, "Instruction", verbatim.*

## Spatial working memory (MTB, run 4)

"Watch which boxes light up, then pick that pattern. Press A for left, X for right."

*Source: `DBP_MTB/dbp_tasks.py`, the task's instruction screen, as shown with the gamepad.*

## ARC (run 6)

"Two example pairs show an input grid of coloured cells and the output grid a hidden rule makes of it. A test input appears with a proposed output. Press accept (Y) if the output follows the rule, or reject (A) if it does not."

*Source: ARC has no instruction text of its own (no README); adapted from the DBP_Welcome documentation, `docs/tools/cogtasks.md`.*
